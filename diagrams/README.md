NEXORA Diagrams | نمودارهای پروژه

فارسی

این پوشه شامل فایل‌های منبع نمودارهای مهندسی نرم‌افزار پروژهٔ NEXORA است. نمودارها با PlantUML نوشته می‌شوند تا قابل ویرایش و نگهداری باشند.

فهرست نمودارها

- "use-case.puml" — نمودار موارد کاربرد و ارتباط بازیگران با سامانه
- "class-model.puml" — نمودار کلاس‌های اصلی سامانه
- "erd.puml" — نمودار موجودیت‌ها و روابط پایگاه داده
- "activity-workout-plan.puml" — نمودار فعالیت ایجاد برنامهٔ تمرینی

برای ویرایش نمودارها، فایل‌های ".puml" را با یک ویرایشگر سازگار با PlantUML باز کنید.

توجه: این فهرست، ساختار مورد انتظار پوشه را مشخص می‌کند. هر نمودار پس از ایجاد و بررسی باید در مخزن ثبت شود.

English

This directory contains the editable source files for NEXORA's software engineering diagrams. The diagrams use PlantUML to support maintainability and version control.

Diagram index

- "use-case.puml" — Actors and system use cases
- "class-model.puml" — Main system classes
- "erd.puml" — Database entities and relationships
- "activity-workout-plan.puml" — Workflow for creating a workout plan

Open the ".puml" files with a PlantUML-compatible editor to edit the diagrams.

Note: This index describes the expected directory structure. Each diagram should be created, reviewed, and committed to the repository.
