# راهنمای کاربر | User Guide (Draft)

## فارسی
این راهنما پس از پیاده‌سازی و تثبیت رابط کاربری تکمیل می‌شود.

### مدیر باشگاه
1. وارد سامانه شوید.
2. از پنل مدیریت، ورزشکاران و مربیان را ثبت کنید.
3. اشتراک هر ورزشکار را با تاریخ شروع و پایان ایجاد کنید.
4. پرداخت‌های دریافتی را ثبت کنید.
5. گزارش اعضا، اشتراک‌های منقضی و پرداخت‌ها را بررسی کنید.

### مربی
1. وارد حساب مربی شوید.
2. پروفایل و تخصص‌ها را تکمیل کنید.
3. از کتابخانه حرکات، حرکات مناسب را انتخاب کنید.
4. برنامه تمرینی بسازید و ست/تکرار/وزنه را تنظیم کنید.
5. برنامه را به ورزشکار مجاز تخصیص دهید.

### ورزشکار
1. وارد حساب خود شوید.
2. پروفایل، برنامه تمرینی و برنامه تغذیه تخصیص‌یافته را ببینید.
3. وضعیت اشتراک و سوابق پرداخت خود را بررسی کنید.
4. در صورت پیاده‌سازی ثبت تمرین، سوابق تمرین را مشاهده کنید.
